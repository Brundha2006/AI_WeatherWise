About This Project

Project Title: AI WeatherWise API

AI WeatherWise API is a simple Flask-based web application built as a final year B.Sc Computer Science project. It fetches real-time weather data for any city using the OpenWeatherMap API and displays it in a clean, easy-to-understand dashboard.

The project also analyzes the fetched weather data to give simple, safe suggestions about outdoor activities, and keeps a history of all past searches using SQLite.

Technology used: Python, Flask, HTML, CSS, JavaScript, SQLite, OpenWeatherMap API
